## 1. 一句話

給新北法制局訴願承辦人（人均 214 件/年、全台最高）的工作台：
**能算的攤開算式、有出處的標出處、不能負責的段落標紅區交還給人**。

## 2. 範圍（30 小時版，砍過兩輪）

### 2.1 主流程（baseline，必須端到端跑通）

**單一案型：違反洗錢防制法 × 77(2) 訴願逾期**（資料集有 5 份同款歷史案可當測試）

```
輸入（合成訴願書 txt/PDF，或結構化手動輸入表單〔備援〕）
  → 抽取：案件類別／原處分字號／送達方式與日期／訴願提起日／訴願理由要點
  → 期間引擎：30 日期滿日（寄存送達生效、假日順延、在途期間），逐步算式＋法條
  → 相似案例證據面板：前 3 相似歷史案（案由＋結果＋差異），不做法律判定
  → 草稿：三段論骨架（事實欄／理由欄），每段標來源
  → 引用徽章：草稿內每個法條/判解對照 S3 快照，✓有據／⚠已修正（如洗防法 15-2→22）／✗查無
  → 安全草稿模式：偵測到高風險結構（先合後破訊號）→ 結論段封鎖＋紅區標示＋判斷交接卡
```

### 2.2 Stretch（baseline 全綠才做，依序）

1. 第二案型（廢清法 79I 煙蒂級——已驗證高度模板化）
2. C 型訊號擴充（113年/20 保留語氣型）

### 2.3 明確不做（demo 時也不口頭承諾）

- 通用 A/B/C 自動分類器與全案型覆蓋
- 平等原則／「相同事例未為相同處理」的法律判定
- 全量法規庫、外部即時 API、「法規最新狀態」承諾（只顯示**資料快照日期**）
- OCR／手寫辨識；工作量預估；分案儀表板
- 任何未實測的量化宣稱（「零錯誤」「省 X%」）

## 3. 命題四功能對照（簡報必用此表開場）

| 命題功能 | 本 prototype 的回應 | 誠實邊界 |
|---|---|---|
| (1) 擷取與分類 | 抽取層（單案型）＋手動輸入備援 | 訴願書樣本賽方未給，測資為合成（標示＋口頭聲明） |
| (2) 法規推薦＋修正狀態 | 案型法條包＋引用快照徽章（含 15-2→22 真實案例） | 快照日期制，不承諾即時 |
| (3) 相似案例前 3-5 | 證據面板前 3 案＋差異 | 只列證據不下法律結論 |
| (4) 草稿生成 | 三段論骨架填空＋安全草稿模式 | 高風險結論段交還人工——這是特性不是缺陷 |

## 4. 模組規格

### 4.1 期間引擎（demo 主秀｜純 Python，零 LLM）
- 輸入：`{送達方式: 本人簽收|寄存|公示, 送達日, 提起日, 住居地(在途判定), 利害關係人?: bool}`
- 輸出：`{期滿日, 是否逾期, steps: [{描述, 法條, 中間值}], caveats: [...]}`
- 規則：訴願法 14 I（次日起 30 日）、寄存送達即生效（行政程序法 74）、期滿逢假日順延（民法 122）、在途期間（訴願法 16）
- **不自動判定**：14 II「知悉時」、15 回復原狀、80 條職權撤銷——輸出 caveat 請人工確認
- 驗收：資料集 77(2) 歷史案全數復現（含 113年/03 寄存＋週六順延）；單元測試 ≥15 案例

### 4.2 抽取層（Bedrock LLM）
- 單案型 prompt（`prototype/prompts/extract-mlpa.md`），輸出 JSON schema 固定
- 失敗即降級：任一必填欄位信心不足 → UI 轉手動輸入表單（不硬猜）
- 驗收：5 份合成測資（1 份刻意做髒：仿 113年/03 寫錯機關字號）抽對 ≥4，髒的那份必須觸發降級或人工確認

### 4.3 相似案例證據面板
- 向量檢索（Bedrock KB）於 101 份決定書，回前 3＋逐案「同/異」欄位（案由、法條、結果）
- 禁：任何「本件應比照」措辭

### 4.4 草稿生成＋安全草稿
- 模板：已驗證的逐字級句式（起手式/收尾句）＋ LLM 填空（事實欄、爭點）
- 安全草稿觸發：先合後破訊號（規則：主文傾向維持但偵測到獨立法律障礙關鍵詞）→ 結論段以紅區佔位，附「判斷交接卡」（列出要人決定的具體問題＋兩份真實案出處 114年/19、113年/20）
- 驗收（qa-legal 對抗餵食）：兩份已知 C 型案丟入，**生成了結論段＝P0**

### 4.5 引用快照驗證徽章
- 只掃草稿實際引用；對照 `s3://…/laws-snapshot/`＋修法對照表（15-2→22 內建）
- 三態：✓／⚠已修正（附新條號）／✗查無（阻擋送出）
- demo 必含一個故意的假判例字號被攔下

## 5. 資料與誠信（憲法 §2 §3 §6 落地）
- 測資檔名 `synthetic-*`；demo 首頁常駐「合成測資聲明」badge；簡報有測資出處 slide
- 資料集 → S3 私有 bucket（僅供競賽之用）；repo 只進合成測資
- 已寄/待寄賽方：訴願書樣本＋評分權重＋賽前預作規則（三合一信）
