# plans/ — superpowers 式計畫文件

本專案不用 prospec（sprint、30 小時、用後即棄）。每個工作包一份 plan，格式：

```markdown
# <工作包名>（YYYY-MM-DD）
## 目標         一句話，做完使用者/評審能看到什麼
## 步驟         有序清單，每步可獨立驗
## 驗收條件     可執行的檢查：跑什麼、看到什麼。「應該可以」不算
## 備援方案     到「最遲放棄時刻」沒綠，降級成什麼
## 最遲放棄時刻 相對時點（如 D1 18:00）
## 預估時數     plan-guardian 記帳用
```

規矩：開工前 plan-guardian 驗 plan、完成時驗證據。詳 `CONSTITUTION.md` §5、§8。
