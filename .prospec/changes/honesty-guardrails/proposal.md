# honesty-guardrails

前端把 `done` 的兩個誠實例外欄位落地——`redirect` 非 null 時不顯示 AI 算的天數／金額，`dropped_refs` 非空時標示引用有問題。本期不做完整三層燈號 UI，後端欄位照送不動。

---

## Background

**本期範圍刻意收窄（2026-09-12 Ci 拍板）：** `done` 事件實際上帶完整的分層誠實燈號欄位（`lamp`／`tier`／`origin`／`why`／`refs[]`／`dropped_refs[]`／`redirect`／`refine_used`／`memory`／`session_truncated`／`model_id`，完整定義見 `docs/spec/2026-09-12-chat-honesty-lamps.md` §4.4）。**本期前端不做燈號 UI**——這些欄位已實作、已由 AC5–AC12 實跑驗過，為了少送幾個 JSON 欄位去改 `classify_answer` 與 `done` 組裝，風險遠大於收益（`docs/handoff/2026-09-12-frontend-contract-v2.md:344-349`）。

**但兩項例外必須做，因為那不是「畫得好不好看」，是「會不會講假話」（§2.4.1）：**

1. **`redirect` 非 null → 不得顯示 agent 講的任何天數。** 使用者問期限／天數／金額時，機械規則對**問題**做字面比對，寧可誤判也不漏判，強制紅燈並帶上 `redirect`。前端完全不處理的話，LLM 算的天數會直接出現在畫面上——期間算錯在訴願案有實質後果，是 `CONSTITUTION` §4 的紅線。最小做法：`redirect` 非 null 時不顯示 `answer`，改顯示 `reason` 加一顆 CTA，按下去捲到程序審查卡。
   > **CTA 真的捲得到，沒有後端驗收涵蓋**——後端 AC7 只驗 `redirect.endpoint` 的值，前端要自己補一條驗收（例：點 CTA 後程序審查卡進入視窗且被 highlight）。契約點名「之前有過一顆死鈕就是這樣來的」。
2. **`dropped_refs` 非空 → 該則回答要標「引用有問題」。** 代表模型引了一個不存在於白名單的字號，不顯示就等於讓編造的引用直接送到承辦人眼前，踩 `CONSTITUTION` §2（引用必可驗）。最小做法：該則下方一行灰字「此則含無法對應的引用，請勿直接採用」。

這兩項合計大約十行 Vue，不用做三層燈、不用做 `refs[]` 展開清單、不用碰 `lamp`／`tier`／`origin`。

**設計稿文案要同步修正（§6）：** 「草稿只認右側卷宗裡的東西當來源」與後端不符（法規已改走 `overrides.n4_query` 餵回檢索），正確說法是「你挑的法規會成為檢索的查詢詞，查得到才會進草稿」；案例本期仍只是參考資料，右欄要標明。

## User Stories

### US-D1: 期限題不由 AI 回答 [P0]

**作為**陳專員，**我要**系統在我問期限時把我導向可驗算的規則引擎，**才不會**採用一個模型算的天數。

- **D1.1** Given 問「還有幾天可以提訴願」、Then `done.redirect` 非 null 且 `lamp == "r"`。
- **D1.2** 前端在 `redirect` 非 null 時**不顯示 `answer`**，改顯示 `reason` ＋ CTA。**畫面上不得出現任何天數。**
- **D1.3** 點 CTA 後程序審查卡進入視窗且被 highlight。**後端驗收涵蓋不到這條，前端要自己補**——之前有過一顆死鈕就是這樣來的。
- **D1.4** 問句含金額（罰鍰）時同樣命中。**寧可誤判成紅燈，不可漏判。**

**驗**：問五種期限句型實跑；D1.3 用瀏覽器實際點

### US-D2: 編造的引用要被標出來 [P0]

**作為**科長，**我要**系統告訴我哪一句的引用對不上，**才不會**把一個不存在的字號簽下去。

- **D2.1** Given 模型引了白名單外的編號、Then `done.dropped_refs` 非空且該回合 `lamp == "r"`。
- **D2.2** 前端在 `dropped_refs` 非空時標「此則含無法對應的引用，請勿直接採用」。
- **D2.3** 引用偵測對 `C`／`c`／`L`／`l` 四種前綴都認（大小寫不敏感）。

**驗**：既有 `pytest` 有八條回歸測試；新增的是前端顯示

## 不做什麼

- 不做完整三層燈號 UI（`lamp`／`tier`／`origin`／`refs[]` 展開清單）——本期只讀 `redirect` 與 `dropped_refs` 兩個欄位。
- 後端欄位不動：`done` 的燈號組裝與 `classify_answer` 已實作並驗過，本 change 不碰。
- 不改機械判定規則本身（`backend/gate/lamps.py`、`docs/spec/2026-09-12-chat-honesty-lamps.md` 已凍結）。
- 不處理法規母庫「綠燈只代表字號對得回快照」等其餘誠實紅線的 UI（那些本期也不做燈號展示，若之後補齊燈號 UI 才會一併處理）。
